# QuickMock - 页面点选与内容搜接口改写 Chrome 插件

一款专为前端本地联调设计的轻量级 Chrome 浏览器插件（Manifest V3），无需任何构建工具即可直接加载。

## 核心特性

1. **长按快捷键点选页面元素直接改写**：按住 `Shift`（支持点击录制修改为任意按键）并将鼠标移至页面上的文字、表格或 ECharts 图表，实时预览匹配的接口；点击左键直接弹出页内改写框并定位到对应字段。
2. **按页面文本反向搜接口**：在右侧常驻侧边栏输入页面上渲染的姓名、编号或数值，立即检索出对应的接口及命中内容片段。
3. **图表/列表一键扩充多条数据**：内置 `+1 条`、`+5 条`、`+10 条` 数组造数按钮，自动识别接口 JSON 中的数组并克隆、随机化数值，一键验证多数据图表展示效果。
4. **常驻右侧边栏 & 自动刷新生效**：基于 Chrome 原生 `Side Panel`，点击页面不会关闭面板，点击保存自动同步规则并刷新页面生效。

## 安装方式

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
2. 开启右上角的 **开发者模式**。
3. 点击左上角 **加载已解压的扩展程序**，选择本项目文件夹即可。
